# Wagons Motion Deblur

An advanced computer vision project developed during a hackathon. This repository contains the source code and models used to detect, analyze, and correct motion blur in images, specifically tailored for vehicular or wagon tracking.

## Overview
Motion blur can severely degrade the performance of optical character recognition (OCR) and object tracking systems. This project implements deblurring algorithms to restore sharp features to distorted images, allowing for higher accuracy in downstream computer vision tasks.

## Key Technologies
- Image Processing Algorithms
- Computer Vision Frameworks
- Python

## Project Structure
- src/ - Contains the core deblurring logic and mathematical transformations.
- models/ - Houses any pre-trained weights or machine learning models utilized.
- data/ - Sample images for testing the deblurring pipeline.
